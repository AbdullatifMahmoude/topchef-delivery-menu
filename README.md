# 🍗 مطعم توب شيف | Top Chef Restaurant
### تطبيق كابتن الدليفري وتصميم المنيو الرسمي الحديث

هذا المستودع يحتوي على التصاميم التفاعلية الخاصة بمطعم **توب شيف**:
1. **تطبيق كابتن الدليفري (`/`)**: واجهة متكاملة لإدارة رحلات التوصيل، استلام الكاش، العهدة المالية، وتأكيد التسليم.
2. **منيو الزبائن الرسمي (`/menu/`)**: واجهة عصرية وسلسة تعرض أقسام المنيو، المشويات على الفحم، المقليات، السندوتشات، والسلة الشرائية.
